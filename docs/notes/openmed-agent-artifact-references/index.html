为 OpenMed Agent 引入产物引用，避免在追踪中写入内容

追踪记录需要知道输出是什么，但不应把临床文本、文件名、路径或 URL 一起写进去。

PR 记录了引用契约及 Agent 单元测试、类型和严格文档构建；未用临床实数据。

给追踪系统一个引用，而不是一份拷贝

如果把输出原文或落地路径带进追踪，观察链路会多持有一份敏感数据。引用可以让日志确认某个产物存在，至于读取内容，则交给有独立权限的产物层。

把“不传内容”写成可检查的契约

我定义了版本化的不可变引用和允许的产物类型，只接受必要的标识、摘要和大小等元数据。遇到多余字段、内嵌数据、路径或非法 ID 时拒绝输入，错误码不回显原值。引用本身不读文件也不请求网络。

公开验证覆盖引用和 Agent 单元测试以及文档构建。它不是加密、鉴权、存储或脱敏服务；不会因为用了引用就自动让整条链路合规。
